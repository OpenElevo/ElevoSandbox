# Admin 管理后台交互设计文档

日期：2026-03-11（修订 v4 — 技术评审修订）

## 概述

本文档为 Elevo Admin 管理后台的交互设计规范，面向产品/设计团队评审和对齐。涵盖全局交互规范和各页面的详细交互设计。

技术参考：[Namespace 管理与 Admin 后台设计](./2026-03-11-workspace-admin-design.md)

**界面语言：** 中文

## 一、全局框架与导航

### 1.1 整体布局

采用**左侧导航 + 顶栏 + 内容区**三栏布局：

```
┌──────────────────────────────────────────────────┐
│  Logo / Elevo Admin          [Admin ▾] [退出登录] │  ← 顶栏 (64px)
├────────────┬─────────────────────────────────────┤
│            │                                     │
│  仪表盘     │     内容区                           │
│  租户       │     (面包屑导航)                      │
│  Share     │                                     │
│  Sandbox   │     页面标题 + 操作按钮                │
│  审计日志   │     ─────────────                    │
│            │     主要内容                          │
│            │                                     │
│            │                                     │
│  ──────── │                                     │
│  [收起侧栏] │                                     │
└────────────┴─────────────────────────────────────┘
   (200px)          (自适应，最小 960px)
```

### 1.2 侧边栏

- 固定宽度 200px，可折叠为 64px（仅显示图标）
- 折叠状态持久化到 localStorage
- 导航项按功能重要性排列，无分组头
- 当前页面的导航项高亮（背景色变化 + 左侧 3px 指示条）
- 二级页面（如租户详情）仍高亮父级导航项

### 1.3 顶栏

- 左侧：产品 Logo + "Elevo Admin" 文字
- 右侧：Admin 身份标识 + 退出登录按钮
- 退出登录：点击后弹出确认对话框 →"确认退出？" → 确认后清除 JWT，跳转登录页

### 1.4 面包屑

- 位于内容区顶部，紧贴页面标题上方
- 格式：`仪表盘 / 租户 / Team Alpha`
- 每一级可点击跳转
- 列表页（一级页面）不显示面包屑
- 详情页（二级页面）显示面包屑

### 1.5 响应式策略

- 目标设备为桌面浏览器，最小支持宽度 1280px
- 低于 1280px 时侧边栏自动折叠
- 不做移动端适配

## 二、通用交互模式

### 2.1 列表页通用结构

所有列表页（租户、Share、Sandbox、审计日志）遵循统一结构：

```
┌─────────────────────────────────────────────────┐
│  页面标题                          [+ 创建XXX]    │
├─────────────────────────────────────────────────┤
│  搜索框          筛选器1 ▾   筛选器2 ▾   [重置]   │
├─────────────────────────────────────────────────┤
│  ┌─表格───────────────────────────────────────┐ │
│  │ □  名称↑   状态    创建时间    操作          │ │
│  │ □  item1   ●活跃   03-11      [查看][删除]  │ │
│  │ □  item2   ○停用   03-10      [查看][删除]  │ │
│  │ ...                                        │ │
│  └────────────────────────────────────────────┘ │
│             ← 1 2 3 ... 10 →    每页 20条 ▾     │
└─────────────────────────────────────────────────┘
```

### 2.2 搜索

- 搜索框位于筛选区左侧，placeholder 为"搜索名称或 ID..."
- 支持按名称模糊搜索和按 UUID 精确匹配
  - 仅当输入完整匹配 UUID v4 格式（`xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx`）时，自动切换为 ID 精确查找
  - 输入过程中（不完整的 UUID 片段）仍走名称模糊搜索
- 输入后 **300ms 防抖**自动触发搜索，无需按回车
- 搜索框右侧有清除按钮（×），点击清空并重新加载

### 2.3 筛选

- 筛选器为下拉选择（Select），展示在搜索框右侧
- 筛选变更后立即触发请求
- "重置"按钮：清除所有筛选条件和搜索关键词，恢复默认

### 2.4 表格

- 表头支持点击排序（仅对创建时间、更新时间列），点击切换 升序→降序→默认
- 行操作按钮以**文字链接形式**展示，不用图标按钮
- 危险操作（删除）使用红色文字
- 表格行 hover 时显示浅灰背景
- 列宽：名称列自适应，状态/时间列固定宽度，操作列固定宽度靠右

### 2.5 分页

- 底部居中，显示页码 + 前后翻页按钮
- 右侧显示每页条数选择器（10 / 20 / 50 / 100）
- 切换分页或每页条数时，滚动回内容区顶部
- URL 同步分页参数（`?page=2&page_size=20`），支持浏览器后退
- 显示总数信息："共 N 条"

### 2.6 批量操作

- 仅 Sandbox 列表页有批量操作（批量清理停止的 Sandbox）
- 表头复选框全选当前页
- 选中后，表格上方浮现操作栏："已选 N 项 [选择所有匹配结果（共 M 项）] [批量删除] [取消选择]"
- "选择所有匹配结果"链接仅在当前筛选结果超过一页时显示，点击后切换为跨页全选模式
- **跨页全选实现：** 跨页全选模式下，前端记录当前筛选条件（而非逐个 ID），点击 [批量删除] 时调用 `POST /api/v1/sandboxes/batch-delete` 的 `filter` 模式（传递筛选条件而非 ID 列表），由后端按条件查询并逐个删除

### 2.7 加载状态

| 场景 | 表现 |
|------|------|
| 首次加载列表 | 表格区域显示骨架屏（Skeleton），保持表头可见 |
| 翻页/筛选 | 表格上方显示细长进度条（类似 NProgress），表格内容变灰半透明 |
| 详情页加载 | 整个内容区显示 Spin 加载器 |
| 按钮提交中 | 按钮变为 loading 状态（旋转图标 + 禁用），防止重复点击 |

### 2.8 空状态

| 场景 | 表现 |
|------|------|
| 列表无数据（无筛选） | 居中插图 + 描述文字 + 创建按钮。如"还没有 Share，立即创建第一个" |
| 列表无数据（有筛选） | 居中插图 + "未找到匹配结果" + "清除筛选条件"链接 |
| 详情页子列表为空 | 行内提示文字 + 添加按钮。如权限列表为空："暂无权限分配，点击添加" |

### 2.9 反馈模式

#### 全局消息提示（Message）

- 成功操作：顶部居中，绿色成功提示，3 秒自动消失。如"Share 创建成功"
- 操作失败：顶部居中，红色错误提示，5 秒自动消失，可手动关闭。显示具体错误信息

#### 确认对话框（Modal）

- 用于不可逆操作：删除资源、撤销 API Key
- 标题明确说明操作内容
- 正文说明影响范围（如"删除 Share 将同时移除所有权限记录"）
- 双按钮：[取消]（默认焦点）和 [确认删除]（红色，危险操作）
- 删除类确认框中需用户**输入资源名称**才可确认（防误操作），适用于租户和 Share 删除

### 2.10 表单验证

- 实时校验：输入框失焦（onBlur）时触发
- 提交校验：提交时再次校验全部字段
- 错误提示显示在对应字段下方，红色文字
- 字段获得焦点时错误提示不消失，修正后实时清除

### 2.11 表单脏数据保护

所有抽屉/对话框中的表单均支持脏数据检测：
- 当表单内容已修改（dirty state）时，用户通过点击 ×、点击遮罩、或按 ESC 试图关闭，弹出确认提示："有未保存的内容，确认放弃？"
- 双按钮：[继续编辑]（默认焦点）和 [放弃]
- 表单未修改时直接关闭，无需确认

### 2.12 全局错误处理

| HTTP 状态 | 全局处理 |
|-----------|---------|
| 401 | 清除 JWT，跳转登录页，提示"登录已过期，请重新登录" |
| 403 | 当前页面内 Message 提示"权限不足" |
| 404 | 详情页：显示"资源不存在"空状态页，带"返回列表"按钮 |
| 409 | 表单内显示冲突信息（如"名称已存在"） |
| 429 | Message 提示"请求过于频繁，请稍后再试" |
| 500 | Message 提示"服务器错误，请稍后重试" |
| 网络断开 | Message 提示"网络连接失败，请检查网络" |

#### JWT 自动续期

Axios 响应拦截器检测 `X-Refreshed-Token` 响应头，若存在则自动更新 localStorage 中的 JWT Token，对用户无感知。

**并发安全：** 多个并发请求可能同时返回 `X-Refreshed-Token`，需使用全局互斥标记（如 `isRefreshing` 变量）确保只更新一次，采用"最后写入"语义：

```typescript
let isRefreshing = false;

axios.interceptors.response.use((response) => {
  const newToken = response.headers['x-refreshed-token'];
  if (newToken && !isRefreshing) {
    isRefreshing = true;
    localStorage.setItem('token', newToken);
    // 下一个事件循环重置，允许后续续期
    setTimeout(() => { isRefreshing = false; }, 1000);
  }
  return response;
});
```

**前端路由 404：** 访问不存在的前端路由时，显示通用 404 页面：居中显示"页面不存在"插图 + "返回仪表盘"按钮。

### 2.13 时间显示规范

| 场景 | 格式 | 说明 |
|------|------|------|
| 列表页时间列 | `YYYY-MM-DD HH:mm` | 精确到分钟 |
| 详情页时间字段 | `YYYY-MM-DD HH:mm:ss` | 精确到秒 |
| 审计日志时间列 | `YYYY-MM-DD HH:mm:ss` | 精确到秒 |
| 相对时间补充 | hover 时 Tooltip 显示完整时间 | 可选展示"3 分钟前"等相对时间 |

**时区规范：** API 返回 UTC（ISO 8601 格式），前端统一转换为浏览器本地时区展示。所有时间列 Tooltip 中显示完整时间时，附带时区标识（如 `2026-03-11 18:00:00 CST`）。

### 2.14 权限级别中文映射

| API 值 | 中文展示 | 说明 |
|--------|---------|------|
| `read` | 读取 | 查看信息、读取文件、列目录 |
| `write` | 写入 | 包含读取 + 写文件、管理 Sandbox |
| `execute` | 执行 | 包含写入 + 终端、进程操作 |
| `admin` | 管理 | 包含执行 + 删除、权限管理、设置 |

权限下拉选择器中展示为"读取 (read)"格式。

### 2.15 空值与缺省展示

| 场景 | 展示 |
|------|------|
| 字段值为空字符串（如描述为空） | 显示灰色占位文字"暂无描述" |
| Sandbox 名称为 NULL | 显示灰色占位文字"未命名" |
| 字段值为 NULL | 显示"—" |
| 时间字段为 NULL（如 API Key 从未使用） | 显示"从未使用" |

**路由：** `/login`

**布局：** 全屏居中，不显示侧边栏和顶栏。

### 交互细节

**密码输入框：**
- 默认隐藏密码，右侧有眼睛图标切换显示/隐藏
- 按 Enter 键等同于点击登录按钮
- 页面加载后自动聚焦到密码输入框

**登录按钮：**
- 密码为空时按钮禁用（灰色）
- 点击后按钮变为 loading 状态，文字变为"登录中..."
- 登录成功：跳转到仪表盘（或用户之前尝试访问的页面）
- 登录失败：密码框下方显示红色错误提示"密码错误"，保留密码内容不清空，密码框重新聚焦
- 连续失败不做前端限流（后端有全局速率限制）

**路由守卫：**
- 已登录用户访问 `/login`：自动重定向到仪表盘
- 未登录用户访问其他页面：记录目标路径，重定向到 `/login`，登录成功后跳回

### 统计卡片

- 4 张统计卡片，单行横排等宽排列
- 每张卡片包含：图标 + 标题 + 数字 + 说明文字

  - **租户**：活跃数 / 总数

## 五、租户管理

### 5.1 列表页

**路由：** `/tenants`

**页面标题：** 租户管理

#### 筛选器

- 搜索框：按名称搜索
- 状态筛选：全部 / 活跃 / 已停用
- 存储类型筛选：全部 / 托管 / 远程

#### 表格列

| 列名 | 内容 | 宽度 |
|------|------|------|
| 名称 | 租户名称，可点击跳转详情 | 自适应 |
| 描述 | 截取前 50 字符 | 200px |
| 状态 | `活跃`（绿色标签）/ `已停用`（灰色标签） | 80px |
| 存储类型 | `托管` / `远程` | 80px |
| Share 数 | 创建的 Share 数量（API 响应中的 `share_count` 字段） | 100px |
| API Key 数 | 活跃的 Key 数量（API 响应中的 `active_api_key_count` 字段） | 100px |
| 创建时间 | 支持排序 | 160px |
| 操作 | [查看] [停用/启用] [删除] | 160px |

#### 操作按钮行为

- **[停用]**：确认对话框"停用后该租户的所有 API Key 将立即失效，确认停用 {name}？" → 调用 `POST /tenants/{id}/deactivate` → 确认后列表刷新
- **[启用]**：确认对话框"确认启用租户 {name}？" → 调用 `POST /tenants/{id}/activate` → 确认后列表刷新
- **[删除]**：分三种情况
  - 有活跃 Share 或活跃 Sandbox：弹窗提示"该租户有 N 个 Share 和 M 个活跃 Sandbox，请先清理后再删除"，**禁止删除**
  - 有活跃 API Key 但无 Share/Sandbox：弹窗警告"该租户有 N 个活跃 API Key，删除后这些 Key 将永久失效。确认删除？" → 需输入租户名称确认
  - 无 Share、无活跃 Sandbox、无活跃 Key：普通确认对话框 → 需输入租户名称确认

- [批量删除]：确认对话框"确认删除选中的 N 个 Sandbox？运行中的 Sandbox 将被强制停止。此操作不可撤销。"
  - **当前页选中模式**：调用 `POST /api/v1/sandboxes/batch-delete`，传递 `ids` 列表
  - **跨页全选模式**：调用 `POST /api/v1/sandboxes/batch-delete`，传递 `filter` 条件（当前筛选参数）
  - 提交后按钮变为 loading 状态，等待响应
  - 全部成功时：Message 提示"成功删除 N 个 Sandbox"，刷新列表
  - 部分失败时：Message 提示"成功删除 M 个，N 个删除失败"，刷新列表

**无创建入口：** Sandbox 通过 API/SDK 创建，Admin 后台不提供直接创建 Sandbox 的入口。

#### 筛选区域

| 资源类型 | 单选下拉 | 全部 / 租户 / Share / API Key / 权限 |

#### 表格列

| 列名 | 内容 | 宽度 |
|------|------|------|
| 时间 | `YYYY-MM-DD HH:mm:ss`，默认时间倒序 | 170px |
| 操作 | 自然语言描述（如"创建租户"、"授予权限"） | 120px |
| 执行者 | Admin / 租户名称 | 120px |
| 资源类型 | 租户 / Share / API Key / 权限 | 100px |
| 资源名称 | 被操作资源名称（见下方跳转规则） | 自适应 |
| IP 地址 | 客户端 IP | 140px |
| 详情 | [查看详情] 展开链接 | 80px |

#### 资源名称跳转规则

| 操作类型 | 展示方式 |
|---------|---------|
| `*.create`、`*.update`、`*.grant` | 蓝色可点击链接，跳转到对应资源详情页 |
| `*.delete`、`*.revoke` | 灰色纯文本 + 删除线样式，不可点击 |

- 展开区域显示 `detail` JSON 内容，格式化为可读的键值对
- 同一时间只展开一行

#### 特殊说明

- 审计日志**仅追加**，不可删除，不可修改
- 当筛选结果超过 1000 条时，表格下方提示"结果较多，建议缩小时间范围"
